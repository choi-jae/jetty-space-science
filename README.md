# JETTY SPACE v0.9.8.1 · GLB 조립 오류 수정

이번 수정판은 v0.9.8의 3개 옵션 제거(치마, 클립보드, 피부색 선택) 및 접속마다 초기 캐릭터에서 시작하기 기능을 그대로 유지합니다.

## 수정 원인

이전 v0.9.8 `public/avatar-parts.js`에서 치마 파츠를 제거하면서 실수로 `add('bottom','bottom','Body')` 호출이 남았습니다. `Body`는 GLB 파일 묶음이 아니기 때문에 아바타 조립 중에 오류가 발생합니다. 해당 호출을 삭제했습니다.

## 실행

새 폴더에서 `npm.cmd install`, `npm.cmd run check`, `npm.cmd start` 실행 후 `http://localhost:3000`에 접속합니다.

서버가 이전 버전을 계속 제공하지 않도록 기존 실행 중인 서버를 `Ctrl+C`로 종료한 뒤 새 폴더에서 시작하세요.

GLB 8종 여성형 헤어, 남성형 헤어, 단진동 시뮬레이터 왕복 연결, 색상 옵션과 모바일 대응은 그대로 유지합니다.

## 검증 범위

문법 및 GLB 필수 노드 검사는 포함되어 있지만, 실제 브라우저 WebGL 렌더링 검사는 별도 확인이 필요합니다.
